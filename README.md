# Ganeshka

Projet front-end basé sur React 18 et Create React App. Le projet déclare TypeScript, Material UI, styled-components et D3, ainsi que Storybook pour explorer les composants.

## Lancer le projet

Depuis la racine du dépôt, avec Node.js et npm installés :

```sh
npm install
npm start
```

| Commande | Usage |
| --- | --- |
| `npm test` | Lancer les tests |
| `npm run build` | Générer le build de production |
| `npm run storybook` | Ouvrir Storybook sur le port 6006 |
| `npm run build-storybook` | Générer la version statique de Storybook |
